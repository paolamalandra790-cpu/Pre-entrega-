
# Objetivo
Práctica de selectores CSS para fichas de talentos.

### 1. Selector de Etiqueta
``` cssñ
h2 {
  color: #2c3e50;
  font-family: Arial;
}


### 2. Selector de Clase
``` css

.tarjeta-talento {
  border: 1px solid #ccc;
  border-radius: 10px;
  padding: 15px;
}
``` 

### 3. Selector de ID
``` css
#talento-destacado {
  background-color: gold
}
```

### 4. Selector Combinado
``` css
div .habilidad {
  font-weight: bold;
}
```
